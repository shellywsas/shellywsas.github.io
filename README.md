**Shelly Widman Sasson - Software Developer & Web Creator Showcase**

## ✨ מה כולל האתר?
* **28 פרויקטים מובחרים ומסוננים** מתוך חשבון ה-GitHub (`shellywsas`), ללא כפילויות וללא דפים תקולים.
* **קישור כפול בכל כרטיסייה**:
  * 🌐 **הדגמה חיה (Live Demo)** - פתיחה מיידית של האפליקציה ב-GitHub Pages.
  * 💻 **קוד מקור (GitHub Code)** - מעבר למאגר הקוד הפתוח.
* **📱 ברקוד QR אינטראקטיבי לכל פרויקט**: מאפשר למראיינים לסרוק את המסך עם הטלפון ולהתנסות באפליקציה/משחק תוך 2 שניות!
* **💡 חלון 'תקציר לראיון' (Interview Pitch)**:
  * הצורך/הבעיה שנפתרה
  * ארכיטקטורה וסטאק טכנולוגי
  * אתגרים הנדסיים מעניינים ודגשים להסבר בראיון
* **🔍 מנוע חיפוש וסינון מהיר**: חיפוש טקסט חופשי, חלוקה ל-5 קטגוריות ראשיות (דגל, EdTech, חדרי בריחה, משחקים, כלים, שפות).

## 🚀 פריסה ל-GitHub Pages
הקובץ `index.html` הוא עצמאי (Single-page App) ללא תלויות שרת או Build steps.
ניתן להריץ את `deploy-to-github.bat` להעלאה מהירה למאגר `shellywsas.github.io`.
